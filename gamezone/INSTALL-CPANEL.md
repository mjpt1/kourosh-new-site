# نصب گیم‌زون با دیتابیس دستی در cPanel

این نصب‌کننده فقط برای نصب تازه و یک دیتابیس خالی است. اگر سایت شما قبلاً نصب شده و `config.php` دارد، نصب متوقف می‌شود. برای سایت موجود ابتدا از فایل‌ها و دیتابیس پشتیبان بگیرید؛ از نصب‌کننده برای بازنصب استفاده نکنید.

## پیش‌نیازها

PHP 8 یا جدیدتر با افزونه `pdo_mysql`، HTTPS و دسترسی نوشتن PHP به پوشه سایت لازم است. نیازی به توکن API نیست.

## ساخت دیتابیس در cPanel

۱. به cPanel وارد شوید و بخش **MySQL Databases** یا **Manage My Databases** را باز کنید.
۲. یک دیتابیس جدید بسازید و نام کامل آن، شامل پیشوند حساب cPanel، را یادداشت کنید.
۳. در بخش MySQL Users یک کاربر تازه و رمز قوی بسازید. نام کامل کاربر، همراه پیشوند، و رمز را نگه دارید.
۴. در بخش Add User To Database، کاربر را به دیتابیس تازه اضافه کنید و **ALL PRIVILEGES** را انتخاب و ذخیره کنید. دیتابیس باید خالی باشد.

## نصب فروشگاه

۱. ZIP را در پوشه موردنظر مثل `public_html/kn` استخراج کنید. فایل `.htaccess` باید همراه فایل‌ها باشد. فایل ZIP بارگذاری‌شده را پیش از باز کردن نصب‌کننده از هاست حذف کنید؛ زیرا کلید نصب در آن وجود دارد.
۲. در File Manager فایل `installer-key.php` را باز کنید و مقدار داخل نقل‌قول را بردارید. کلید و رمزها را برای کسی نفرستید.
۳. آدرس HTTPS سایت را با افزودن `/install.php` باز کنید. کلید نصب، میزبان MySQL (معمولاً `localhost`)، نام کامل دیتابیس، نام کامل کاربر و رمز کاربر دیتابیس را وارد کنید.
۴. نام و ایمیل مدیر و یک رمز جدید مدیر را وارد و نصب را اجرا کنید. جدول‌ها و محصولات نمونه ساخته می‌شوند و اطلاعات اتصال در `config.php` ذخیره می‌شوند. نصب‌کننده دیتابیس غیرخالی را نمی‌پذیرد.
۵. پس از نصب، `install.php` را حذف کنید و `config.php` را محرمانه نگه دارید. کلید پس از نصب حذف می‌شود. از صفحه حساب کاربری با حساب مدیر وارد شوید.
۶. محصولات نمونه تا تعیین ریجن واقعی توسط مدیر قابل سفارش نیستند. قیمت و موجودی و سازگاری ریجن را بررسی کنید. پرداخت آنلاین و تحویل خودکار کد فعال نیستند.

اگر نصب متوقف شد ممکن است جدول‌های ناقص در دیتابیس تازه باقی مانده باشند؛ یک دیتابیس خالی دیگر انتخاب کنید. اگر قفل `.install-running` باقی ماند، تنها پس از اطمینان از پایان پردازش آن را در File Manager حذف کنید. اطلاعات یک سایت فعال را حذف نکنید.

این نصب‌کننده در محیط توسعه به سرور MySQL یا cPanel واقعی متصل نشده است و باید روی هاست واقعی بررسی شود.
